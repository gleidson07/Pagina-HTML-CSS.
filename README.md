💻 Projeto simples de Front-End: Portal de Notícias 📰

Compartilhando mais um projeto desenvolvido durante meus estudos de HTML e CSS.

Este é um projeto simples e introdutório, desenvolvido principalmente para praticar a estruturação de páginas e a estilização com CSS.

🏠 A página Home é a parte principal do projeto e onde está concentrado o desenvolvimento mais importante. Nela, trabalhei a organização dos menus, seções de notícias, entrevistas, destaques, imagens, cores e estrutura geral da página.

As demais categorias, como Brasil, Internacional, Economia, Saúde, Ciência e Fotos, foram adicionadas apenas como seções complementares, servindo para representar como o portal poderia ser expandido futuramente. Elas não possuem, neste momento, o mesmo nível de desenvolvimento e funcionalidade da Home.

🎯 O principal objetivo foi colocar em prática conhecimentos básicos de HTML5 e CSS3, entendendo melhor como estruturar e organizar uma página web.

É um projeto inicial, mas representa mais um passo na minha evolução como estudante de Tecnologia da Informação e Desenvolvimento Web.
